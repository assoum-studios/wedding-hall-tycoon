# Third-party assets and code

Every 3D model, texture, character, sound and piece of music in the game is generated by the game's own code
(procedural geometry, canvas-drawn textures, Web Audio synthesis). No outside art, model or audio packs are used.

| Asset | Source | License |
|---|---|---|
| three.js (3D engine) | https://github.com/mrdoob/three.js | MIT |
| Lilita One font | Google Fonts via @fontsource/lilita-one | SIL Open Font License 1.1 |
| Lalezar font (Arabic display) | Google Fonts via @fontsource/lalezar | SIL Open Font License 1.1 |
| Nunito font | Google Fonts via @fontsource/nunito | SIL Open Font License 1.1 |
| Cairo font (Arabic body) | Google Fonts via @fontsource/cairo | SIL Open Font License 1.1 |
| AndroidX WebKit | Google (Maven) | Apache 2.0 |
| Vite, TypeScript, tsx (build tools only) | npm | MIT / Apache 2.0 |

## Reference images from the owner
The three reference images (logo, owner customization screen, General Manager character) were used only as a
style guide. They look AI-generated, so their rights are unclear; the game does **not** ship them. The logo was rebuilt
as an original vector (`web/src/ui/logo.ts`), and all characters are original procedural models in the same style.
